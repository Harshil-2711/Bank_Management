🏦 Bank Management System

A simple Bank Management System built with Python using JSON for data storage.

Features

Create a bank account

Deposit money

Withdraw money

View account details

Update account details

Delete an account

Store data in data.json

Technologies

Python 3

JSON

OOP

File Handling

How to Run
python main.py


The program will display a menu where you can choose the required operation.

Note

This project is created for learning and practice purposes. It is not intended for real banking use.
